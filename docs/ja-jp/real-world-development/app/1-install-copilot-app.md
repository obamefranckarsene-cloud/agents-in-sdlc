**[GitHub Copilot アプリ][about-copilot-app]** は、エージェント主導の開発に使うデスクトップ アプリケーションです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、CI パイプラインをすぐに利用できます。自分ですべてを行うのではなく、それぞれ独立したワークスペースで複数のエージェントを並列に指示し、繰り返し作業を自動化するワークフロー向けに設計されています。Node.js をインストールし、プロジェクトのコピーを用意できたので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次のことを行います。

- GitHub Copilot アプリをインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートで準備したバックログを含め、ワークスペースを確認します。
- クイックチャットを試し、アプリについて学びます。

## シナリオ

チームでは、増え続けるバックログに対応するために AI エージェントを使い始めています。Copilot アプリでは、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールしてリポジトリに接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使っている場合、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot アプリをインストールして構成する

GitHub Copilot アプリを使うには、まずインストールします。Windows、macOS、Linux 向けのバージョンが用意されています。アプリをインストールして認証し、Tailspin Toys リポジトリを追加しましょう。

1. ブラウザーで [GitHub Copilot アプリのランディング ページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地が有効な GitHub Enterprise Cloud を使っている場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` ホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリを選択する場合は、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリ選択をスキップし、後からプロジェクトを追加することもできます。
6. テーマを選択するよう求められたら、テーマを選んでオンボーディングを完了します。
7. サイドバーの **Sessions** でリポジトリを探します。すでに表示されていれば、再度追加する必要はありません。
8. まだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した所有者とリポジトリ名を指定します。
9. サイドバーにリポジトリが表示されることを確認します。ここで使用するレイアウトでは、`tailspin-toys` などのリポジトリ フォルダーが **Sessions** の下にまとまり、その下に個々のセッションが表示されます。

## ワークスペースを確認する

プロジェクトを接続したら、アプリの使い方を確認します。サイドバーには主に次の領域があります。

- **New** - 新しい Copilot チャット セッションを開始します。
- **Pull requests** - アプリの GitHub ネイティブ統合を通じて表示されるプルリクエストです。アプリを離れずに、プルリクエストの閲覧と絞り込み、CI 状態の確認、レビューを行えます。
- **Issues** - 同じように表示される issue です。issue を閲覧、絞り込み、issue からセッションを開始できます。
- **Automations** — スケジュールまたはオンデマンドで実行する、保存済みのエージェント タスクです。To Do リストや定期的なプロジェクト保守など、手間のかかる作業を任せられます。振り返りでは次のステップとして紹介しますが、別の演習ではありません。
- **Customize** - MCP サーバー、プラグイン、スキルなどのコンポーネントで Copilot アプリに機能を追加します。Playwright MCP の構成で使用します。
- **Chats** — 独自のブランチやワークスペースを必要としない、質問やブレインストーミング向けの軽い会話です。最初のチャットを開始すると表示されます。表示されない場合は、**Sessions** の横にある **+** を選択してチャットを開始します。
- **Sessions** — リポジトリ フォルダーとエージェント セッションをまとめます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリ ビューが開き、その下のセッションを選択すると会話に戻ります。セッションごとに独立したワークスペースで実行されるため、変更を競合させずに複数のセッションを同時に実行できます。最初のセッションは星評価を追加するときに開始します。

ワークショップを進めながら、ワークスペースを確認していきます。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法が分からない場合や、何かが可能か知りたい場合は、Copilot が案内してくれます。

### 用意されたバックログを確認する

バックログのないプロジェクトはほとんどありません。Tailspin Toys も例外ではありません。テンプレート作成時に用意されたバックログを確認しましょう。

1. サイドバーの **Sessions** で、個別のセッションではなく Tailspin Toys のリポジトリ フォルダーを選択します。その後、リポジトリ上部のナビゲーションにある **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルを探します。
   - Allow users to filter games by category and publisher
   - Update our repository coding standards
3. issue を選択して詳細を読みます。各 issue からエージェント セッションを開始できます。最初の小さな変更を終えた後、フィルター issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot アプリに追加したリポジトリの項目だけが表示されます。他のリポジトリの作業項目を確認するには、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリの使い方を知るには、アプリ自体について質問してみましょう。**クイックチャット**なら、ブランチや worktree を作成せずに質問やブレインストーミングができます。セッションを必要としない、すぐに終わる質問に適しています。

1. サイドバーで **Chats** の横にある **+** を選択し、新しいチャットを開きます。**Chats** がまだ表示されない場合は、**Sessions** の横にある **+** で最初のチャットを開始します。その後 **Chats** が表示されます。
2. アプリのセッションの仕組みを質問します。

   ```plaintext
   How does the GitHub Copilot app use worktrees?
   ```

3. 会話ビューで回答を読みます。各セッションが独立した git worktree で実行されるため、複数のエージェントを並列に実行しても変更が競合しないことが分かります。会話は続けることも、新しいチャットをいつでも開始することもできます。

## まとめと次のステップ

GitHub Copilot アプリをインストールし、プロジェクトを接続して、ワークスペースを確認しました。次のことを学びました。

- アプリをインストールして GitHub にサインインする。
- GitHub リポジトリからプロジェクトを追加する。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つける。
- クイックチャットで、その場限りの質問をする。

次は、最初のエージェント セッションを開始し、ゲーム カードに星評価を表示します。[レッスン 2「星評価を追加する」][next-lesson]に進んでください。
